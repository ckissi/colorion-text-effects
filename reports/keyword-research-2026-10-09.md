# Text-effect keyword research

Research date: October 9, 2026.

The site contained 99 effects before this update. Nine additions bring the
collection to 108. The table below contains every keyword cluster considered
in this research and the related terms selected for the content plan.

This is qualitative keyword research from public search results, creator
examples and the existing catalogue. No keyword-volume tool or Search Console
data was available. Search volume, ranking difficulty and traffic estimates
are not measured. Related CSS phrases are proposed targets, not measured queries.

## Why these nine

Halftone, risograph, letterpress and embroidery extend the collection's tactile
print and material styles. Stickers and paper layers add contrasting borders
and depth. Stretch adds an expressive letter-motion pattern. Candy stripes
and disco tiles add fills that differ from smooth gradients and chrome.

This selection is an editorial judgment about catalogue gaps and visual
variety. Public examples establish recognizable style names, not comparative
search demand. Current typography coverage favors personality, craft and
motion, which supports this direction without proving every individual effect
is a growing search trend.

## Search implementation

Each new effect has its own keyword, URL, title, H1, description and category.
The existing templates include these pages in the sitemap, structured data,
category lists and related-effect links. Each page includes an original
walkthrough, a copyable variation and troubleshooting notes. The generator
supports custom text and colors for all nine additions.

CSS snippets include their required markup, keyframes and reduced-motion
overrides. The extraction rules now accept three-digit effect indices.
